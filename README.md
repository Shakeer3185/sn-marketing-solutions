# SN Marketing Solutions

Static React + Vite + TypeScript + Tailwind-style CSS architecture (custom CSS) business website. No backend or database.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## GitHub Pages

This project uses relative Vite asset paths (`base: './'`) so it can be hosted on GitHub Pages. After pushing to GitHub, enable Pages using GitHub Actions / a static build workflow.

## Before launch

Update the `CONTACT` object in `src/main.tsx` with the real:
- phone number
- WhatsApp number
- Gmail address
- Instagram URL
- Facebook URL

Replace the Unsplash images with your own business images if desired.
